# 📊 Sales Dashboard

An interactive Sales Dashboard built using Python, Pandas, Plotly and Streamlit.

## 🚀 Features
- KPI Cards — Total Sales, Profit, Orders, Customers
- Sales by Region, Category, Segment
- Monthly Sales Trend (Line Chart)
- Top 10 Sub-Categories
- Profit Analysis
- Interactive Filters — Year, Region, Category

## 🛠️ Tech Stack
- Python
- Pandas
- Plotly
- Streamlit

## 📦 How to Run
pip install -r requirements.txt
streamlit run dashboard.py

## 📁 Dataset
Superstore Sales Dataset from Kaggle (9,994 records)
